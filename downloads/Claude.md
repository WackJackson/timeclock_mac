# Claude 长期记忆文档

## 项目概述

**项目名称**: 工作时薪观察器小程序
**技术栈**: 微信小程序 + TDesign组件库
**开发阶段**: 前端逻辑完善阶段（未开始后端开发）

## 项目架构决策

### 关于后端开发的建议（2026-01-29）

**问题**: 前端存在一些逻辑不正确的地方，是先修正前端逻辑，还是直接推进后端开发？

**建议**: 先修正前端逻辑，再考虑后端

**原因**:
1. 明确需求边界 - 理顺前端逻辑后更清楚哪些数据需要后端持久化
2. 这个项目可能不需要后端 - 工资计算、时间统计都可在前端完成，本地存储即可满足单用户使用
3. 降低返工风险 - 前端逻辑不正确会导致后端接口设计不准确
4. 快速验证产品 - 先完善前端可以快速上线验证用户需求

**后端需求评估标准**:
只有在需要以下功能时才考虑后端：
- 云端数据同步
- 数据备份恢复
- 多设备访问
- 数据统计分析

## 核心页面功能记录

### 1. 时薪观察页面 (pages/home)

**最后更新**: 2026-01-29
**状态**: 前端逻辑修正完成 ✅

#### 已完成功能

1. **自定义导航栏**
   - 透明背景，与页面渐变背景融合
   - 标题随页面滚动消失

2. **数据维度切换**
   - 删除TDesign tabs组件，使用自定义按钮
   - 三个维度：日/周/月
   - 按钮样式参考模式选择模块，半透明效果

3. **维度数据动态展示**
   - 已赚金额：今日已赚/本周已赚/本月已赚
   - 进度条：今日进度/本周进度/本月进度
   - 时间标签：根据实际工作日动态显示
     - 日维度：工作开始时间 - 工作结束时间
     - 周维度：本周第一个工作日(周几) - 最后一个工作日(周几)
     - 月维度：本月第一个工作日(几号) - 最后一个工作日(几号)

4. **进度计算逻辑**
   - 基于用户实际工作日设置计算
   - 示例：用户设置周二四六上班，每天8小时
     - 周进度 = 已工作小时数 / (3天 × 8小时)
     - 月进度 = 已工作小时数 / (本月工作日数 × 8小时)

5. **当前进度指示器**
   - 日维度：显示当前时间（如 "14:30"）
   - 周维度：显示当前周几（如 "周三"）
   - 月维度：显示当前几号（如 "15号"）
   - 样式：工作状态绿色（#4ade80），休息状态白色

6. **时间统计优化**
   - 显示小时数，保留一位小数（如 "1.2h"）
   - 金额自动转换为工作时长

7. **本月秒薪格式化**
   - 保留两位小数

#### 技术实现要点

**新增方法**:
- `StorageManager.getWeekEarnings()` - 获取本周收入
- `StorageManager.getMonthEarnings()` - 获取本月收入
- `getWeekWorkDays()` - 获取本周工作日范围
- `getMonthWorkDays()` - 获取本月工作日范围
- `convertToHours()` - 金额转小时数
- `updateProgressByDimension()` - 根据维度更新进度

**数据存储**:
- 今日收入存储：`TODAY_EARNINGS`
- 历史收入存储：`TODAY_EARNINGS_history`（支持跨天/周/月统计）

### 2. 攒钱观察页面 (pages/savings)

**最后更新**: 2026-01-29
**状态**: 修复对话框显示问题 ✅

#### 问题修复

**问题**: 点击+号按钮后，创建愿望对话框能显示但看不到内容，只能看到取消和创建按钮

**原因**:
1. savings.json缺少TDesign组件引用
2. 对话框内容样式对比度不足

**解决方案**:
1. 在savings.json中添加组件引用：
   ```json
   "usingComponents": {
     "t-dialog": "tdesign-miniprogram/dialog/dialog",
     "t-tag": "tdesign-miniprogram/tag/tag"
   }
   ```

2. 优化对话框样式：
   - 标签文字：字号28rpx，深色，加粗
   - 输入框：添加边框，增强可见性
   - 图标选择器：6列布局，图标48rpx，白色背景+边框+阴影
   - 选中效果：蓝色背景，放大1.1倍

- **目标金额**: 数字输入，带¥符号

## 开发规范

### 样式设计原则

1. **半透明效果**: 使用rgba颜色和backdrop-filter实现毛玻璃效果
2. **状态指示**: 工作状态绿色(#4ade80)，休息状态白色
3. **动态适配**: 根据维度/模式动态调整UI元素
4. **可读性优先**: 文字阴影、边框、背景对比度确保清晰可读

### 代码风格

1. **组件引用**: 需要使用TDesign组件的页面必须在json中声明
2. **数据存储**: 优先使用本地存储，考虑历史数据需求
3. **方法命名**: 动词开头，语义清晰（如updateProgressByDimension）
4. **注释**: 关键逻辑添加注释说明
