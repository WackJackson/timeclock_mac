# 数据同步功能说明

## 功能概述

实现了完整的云端数据同步功能，支持跨设备数据共享和备份。

## 同步的数据

所有业务数据都会同步到云端：

- ✅ **用户配置**（userConfig）- 月薪、工作日、工作时段
- ✅ **工作记录**（workRecords）- 每日工作记录
- ✅ **愿望列表**（wishes）- 所有愿望及进度
- ✅ **激活愿望**（activeWish）- 当前激活的愿望ID
- ✅ **今日收入**（todayEarnings）- 当天的收入统计
- ✅ **收入历史**（todayEarningsHistory）- 历史收入记录
- ✅ **首次工作日期**（firstWorkDate）- 工龄计算依据
- ✅ **当前模式**（currentMode）- 工作模式状态

## 同步策略

### 1. 新用户（首次登录）
- 自动上传本地数据到云端
- 建立云端备份

### 2. 老用户（再次登录）
- 智能合并本地和云端数据
- 合并规则：
  - **用户配置**：使用本地最新的
  - **工作记录**：合并两端数据
  - **愿望列表**：去重合并，按创建时间排序
  - **收入历史**：合并所有记录
  - **首次工作日期**：取最早的日期
  - **当前状态**：使用本地的（最新）

### 3. 手动同步
- 用户主动触发同步
- 显示最后同步时间

## 云函数部署

### syncData云函数

**支持的操作：**
- `upload`：上传本地数据到云端
- `download`：下载云端数据到本地
- `sync`：智能同步（推荐）

**部署步骤：**

1. 在微信开发者工具中找到 `cloudfunctions/syncData` 文件夹
2. 右键点击 → 在终端中打开
3. 执行 `npm install` 安装依赖
4. 右键点击 `cloudfunctions/syncData` 文件夹
5. 选择"上传并部署：云端安装依赖"

## 云数据库配置

### 创建user_data集合

1. 打开云开发控制台
2. 进入"数据库"
3. 创建集合：`user_data`
4. 权限设置：**仅创建者可读写**（重要！）

### 数据结构

```javascript
{
  _id: string,                    // 自动生成
  _openid: string,                // 用户openid（自动）
  userConfig: Object,             // 用户配置
  workRecords: Object,            // 工作记录
  wishes: Array,                  // 愿望列表
  activeWish: number,             // 激活愿望ID
  todayEarnings: Object,          // 今日收入
  todayEarningsHistory: Object,   // 收入历史
  firstWorkDate: string,          // 首次工作日期
  currentMode: string,            // 当前模式
  createTime: Date,               // 创建时间
  updateTime: Date,               // 更新时间
  lastSyncTime: Date              // 最后同步时间
}
```

## 使用方式

### 自动同步
- 用户登录后自动触发
- 新用户上传数据
- 老用户合并数据
- 无需用户手动操作

### 手动同步
1. 进入"我的"页面
2. 点击"数据同步"（仅登录后显示）
3. 等待同步完成
4. 查看同步时间

## 注意事项

1. **必须先登录**才能使用同步功能
2. **网络要求**：需要良好的网络连接
3. **数据安全**：云数据库权限设置为"仅创建者可读写"，确保数据隐私
4. **冲突处理**：采用智能合并策略，本地数据优先
5. **频率控制**：登录时自动同步，避免频繁手动同步

## 测试流程

### 测试场景1：新设备登录
1. 在设备A上设置好数据（工作配置、愿望等）
2. 在设备B上登录同一账号
3. 验证数据是否自动同步过来

### 测试场景2：数据合并
1. 在设备A上添加一些工作记录
2. 在设备B上添加不同的工作记录
3. 手动同步，验证两边数据是否都保留

### 测试场景3：手动同步
1. 修改一些配置或添加记录
2. 点击"数据同步"
3. 验证云端数据是否更新

## 故障排查

### 同步失败
- 检查是否已登录
- 检查网络连接
- 查看云函数是否部署成功
- 查看云数据库权限设置

### 数据丢失
- 云端数据会保留，重新同步即可恢复
- 查看云数据库中的user_data集合
- 如需恢复，可手动点击"数据同步"

### 数据冲突
- 系统采用智能合并策略，不会丢失数据
- 工作记录和收入历史会完整合并
- 愿望列表会去重保留
