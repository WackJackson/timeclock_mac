# 云开发部署指南

## 云函数部署步骤

### 1. 配置云开发环境
云开发环境ID已配置为：`timebomp-2g4siacf47b7e567`

### 2. 部署login云函数

在微信开发者工具中：

1. 右键点击 `cloudfunctions/login` 文件夹
2. 选择"在终端中打开"
3. 执行安装依赖：
   ```bash
   npm install
   ```
4. 右键点击 `cloudfunctions/login` 文件夹
5. 选择"上传并部署：云端安装依赖"

### 3. 配置云数据库

在[微信云开发控制台](https://console.cloud.tencent.com/tcb)中：

1. 进入云开发控制台
2. 选择环境：`timebomp-2g4siacf47b7e567`
3. 点击"数据库"
4. 创建集合：`users`
5. 配置权限：
   - 集合名称：users
   - 权限设置：仅创建者可读写（推荐）或所有用户可读，仅创建者可写

### 4. 数据库字段说明

**users集合结构：**
```javascript
{
  _id: string,          // 自动生成
  _openid: string,      // 用户openid（自动添加）
  nickName: string,     // 用户昵称
  avatarUrl: string,    // 用户头像URL
  createTime: Date,     // 创建时间
  updateTime: Date      // 更新时间
}
```

### 5. 测试登录功能

1. 在微信开发者工具中编译项目
2. 点击"我的"页面
3. 点击"点击登录"按钮
4. 授权用户信息
5. 查看云开发控制台的users集合，确认用户数据已创建

## 功能说明

- **登录**：调用云函数login，自动获取openid并存储用户信息到云数据库
- **注册**：首次登录自动创建用户记录
- **更新**：再次登录时更新用户昵称和头像
- **退出**：清除本地存储的用户信息，但云端数据保留

## 注意事项

1. 云函数和数据库均需要在云开发控制台中先开通
2. 确保在真机上测试，模拟器可能无法完全模拟云开发功能
3. 如遇到云函数调用失败，检查：
   - 云开发环境ID是否正确
   - 云函数是否成功部署
   - users集合是否已创建
   - 权限设置是否正确
