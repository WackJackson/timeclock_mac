## 2. 功能详细需求

### 2.1 首次进入/引导设置页

**逻辑描述：** 用户首次打开，强制进入设置流程，否则无法使用核心功能。

**设置项详情：**

1. **月薪设置：** 输入数字。
2. **工作日设定：** 提供周一至周日 7 个复选框，用户勾选（如：周一、三、五）。
3. **时段规划（核心）：**
* **添加时段：** 用户添加“开始时间”和“结束时间”，并输入“时段名称”（默认如：上午搬砖）。
* **自动间隙（休息）：** 系统自动识别两个非连续工作时段中间的时间，标记为“休息/午休”，不可编辑名称，仅做视觉展示。
* *示例逻辑：*
* 用户设：09:00-12:00 (上午)，14:00-18:00 (下午)。
* 系统生成：
* 09:00-12:00 [工作]
* 12:00-14:00 [自动生成：休息]
* 14:00-18:00 [工作]

### 2.2 模块一：时薪观察 (首页)

#### A. 状态判定与视觉

系统每秒轮询当前系统时间，判定落在哪个时间区间：

* **Condition A: 在工作时段内**
* **视觉：** “战斗状态”UI（高饱和度配色，动态呼吸效果）。
* **核心动作：** 金额根据  累加。
* **文案：** 显示当前时段名称（如“上午搬砖中...”）。


* **Condition B: 在休息间隙 或 非工作日**
* **视觉：** “生活状态”UI（低饱和度，宁静安详，如浅绿/淡蓝）。
* **核心动作：** 金额停止跳动（保持当前累计值）。
* **文案：** “可以不用战斗了，请享受生活”。



#### B. 模式切换（Tag记录）

页面提供三个互斥按钮，点击切换记录状态（仅在工作时段有效）：

1. **普通模式** (Default)：默认状态，正常计薪。
2. **燃尽模式**：点击后UI变更为“高能/过载”风格（如红黑配色）。后台记录该时段为“燃尽”。
3. **摸鱼模式**：点击后UI变更为“隐蔽/轻松”风格（如气泡元素）。后台记录该时段为“摸鱼”。
* *注：无论哪种模式，显示的秒薪金额增速不变，仅做统计分类。*



#### C. 数据看板 (维度切换)

点击可切换时间维度，展示对应累计金额 () 与 进度 ()：

* **日维度：**
*  = 今日已过工作秒数 
*  = 今日已过工作秒数 /  (百分比)


* **周维度：**
*  = 本周已过工作日累计金额
*  = (本周已过天数 + 今日时间进度) / 7


* **月维度：**
*  = 本月已过工作日累计金额
*  = 本月已过天数 / 本月总天数



#### D. 倒计时挂件

展示以下时间差（精确到分）：

* **距离休息：** 距下一个“自动生成的休息间隙”还有多久。
* **距离下班：** 距今日最后一个工作时段结束还有多久。
* **距离周末：** 距本周最后一个设定的工作日结束还有多久。
* **距离假期：** 调用法定节假日API，计算距下一个法定长假还有多久。

2. **愿望列表：**

3. **填充逻辑：**

## 3. 异常与边界情况

1. **非连续时段处理：** 用户设置 09:00-10:00 和 10:00-11:00（无缝衔接）。
* *处理：* 系统视为连续工作，中间无休息间隙提示。


2. **跨天工作：** 用户设置时段为 22:00 - 02:00 (次日)。
* *处理：* 逻辑需支持跨天计算，归属为“开始时间”所在日期的薪水，或按自然日切分（建议按“班次”归属为开始日）。


3. **手动修改系统时间：**
* *处理：* 小程序尽量依赖服务器时间或网络时间，防止用户修改本地时间导致金额作弊（如需离线使用，则以本地时间为准，但在联网时校验）。
